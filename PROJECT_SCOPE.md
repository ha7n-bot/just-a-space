# Scope and release authority
Build a bilingual visitor site and a persistent authenticated editorial CMS for the Al Nakheel café. The owner can review the public experience privately and deploy the full server on persistent infrastructure. Commercial launch requires independently verified prices, publishing rights, owner sign-off, an approved controller contact and verified operating configuration. No domain purchases, DNS edits, payments, analytics transmission or public business launch are authorized. Keep the prior GitHub homepage intact. Research material stays out of visitor data. The GitHub review branch is the deliverable.
