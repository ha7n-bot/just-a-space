# Arabic and English editions

The URL is authoritative. /ar and /en have equivalent routes with html lang and dir set to ar/rtl and en/ltr. / defaults to the last explicitly selected language or Arabic. The native language anchors preserve the current route and query. With scripting enabled they also set a one-year first-party jas_lang preference. Menu search and category selections use GET parameters, so a filtered view can be bookmarked and shared.

Public copy lives in web/copy.mjs; administrative strings live in cms/labels.mjs. The owner manages bilingual page content, SEO text, product names and descriptions, categories and image alternatives in the CMS. Published price, date and schedule presentation uses the active Saudi locale.

The layout uses CSS logical properties and source-order navigation. Arabic headings retain connected letter shapes, default tracking and generous line spacing. Brand text uses a Latin-language island where appropriate. Price, date, phone and email values use bidirectional isolation. Product names and translations retain owner-provided variants. Arabic labels use «المنيو» and «زورونا» in customer navigation and «خرائط قوقل» in directions.

The language switch is a native link, the disclosure menu works with a keyboard, and the menu filter and search work with scripting disabled. Clipboard, Web Share and printing controls appear when browser APIs allow their enhancement. The original marketing headline and Arabic spelling remain subject to the owner's review.
